## 1. 구조

```
읽기 : GitHub Pages (정적 파일)      ← 학생·교사 모두 여기서 화면을 받습니다
쓰기 : Google Apps Script + 시트     ← 설정과 학생 응답은 여기 저장됩니다
```

둘을 물리적으로 나눠 두었습니다. 구글이 막혀도 화면은 뜨고, 파일에 적힌 기본값으로 수업이 이어집니다.

**이것은 잠금이 아니라 허들입니다.** 정적 사이트에는 서버가 없어 완전한 접근 통제를 걸 수 없습니다.
주소를 정확히 아는 사람은 페이지 소스를 볼 수 있습니다.
그래서 **평가 문항·정답·채점기준표는 이 저장소에 두지 않습니다.**

## 2. 교사 화면에 들어가기

두 단계입니다. 둘 다 통과해야 열립니다.

1. **계정 확인** — 허용 목록에 있는 계정인지 봅니다.
2. **비밀번호** — 기본값 `ai2026`. 교사 화면 안에서 바꿀 수 있습니다.

한 번 들어오면 **12시간 동안 그 브라우저에서 기억**합니다. 들어올 때 체크를 풀면 기억하지 않습니다.
위쪽 **[잠그기]** 를 누르면 기억을 지우고 문을 다시 엽니다. **공용 컴퓨터에서는 반드시 잠그고 나오세요.**

기억해 둔 통행증도 새로고침할 때마다 서버에 다시 확인합니다.
다른 기기에서 비밀번호를 바꾸거나 계정을 목록에서 빼면, 이 브라우저도 곧바로 다시 물어봅니다.

### 잠겼을 때
Apps Script 편집기에서 **`설정초기화`** 함수를 실행하세요. 다음 세 경우에 모두 씁니다.

- 비밀번호를 잊었을 때
- 내 계정을 목록에서 실수로 지웠을 때
- 비밀번호를 여러 번 틀려 막혔을 때 (한 시간에 열 번 틀리면 십 분 동안 받지 않습니다)

비밀번호와 계정 목록이 맨 처음 값으로 돌아갑니다.

## 3. 구글 로그인 붙이기 ★ 권장

**붙이기 전까지는 '허용 계정'이 잠금이 아니라 허들입니다.**
지금은 계정 주소를 **직접 치는** 방식이라, 주소만 아는 사람이면 다음 칸(비밀번호)까지 갈 수 있습니다.
구글 로그인을 붙이면 **그 계정으로 실제 로그인한 사람만** 비밀번호 칸으로 갑니다.
교사 페이지와 **수업 진행 화면 두 곳 모두**에 한꺼번에 적용됩니다.
한 번만 하면 되고, 넉넉히 잡아 **15분**입니다. **돈은 들지 않습니다.**

> 화면을 보며 하나씩 따라가는 안내서(체크·복사 단추 포함):
> `docs/google-login-setup.html` — 브라우저로 그냥 열면 됩니다.

### 3-1. 프로젝트 만들기

1. [console.cloud.google.com](https://console.cloud.google.com/) 접속 · 처음이면 약관에 동의합니다.
2. 맨 위 왼쪽 **프로젝트 선택** → **새 프로젝트** → 이름 `tonggwa2` → **만들기**
3. 다 만들어지면 뜨는 알림에서 **그 프로젝트를 눌러 선택**합니다.
   선택하지 않으면 다음 단계에서 엉뚱한 프로젝트에 만들게 됩니다.

### 3-2. 인증 플랫폼 시작

**☰ → API 및 서비스 → OAuth 동의 화면** (요즘 화면에서는 **Google 인증 플랫폼**으로 이름이 바뀌어 있기도 합니다)
→ **시작하기** 를 누르고 채웁니다.

| 사용자 지원 이메일 | 본인 계정 |
| 대상 | **외부** |
| 연락처 정보 | 본인 이메일 |

**‘외부’인 까닭** — **내부**로 하면 `namkang.sen.hs.kr` 계정만 로그인할 수 있어
`cadrical@gmail.com` 으로는 못 들어옵니다(게다가 학교 계정으로 프로젝트를 만들어야 고를 수 있습니다).
두 계정을 다 쓰시니 **외부**가 맞고, 대신 다음 절에서 들어올 수 있는 사람을 **두 명으로 못 박습니다.**

### 3-3. 들어올 수 있는 사람을 두 명으로 못 박기

왼쪽 **대상(Audience)** → 게시 상태는 **테스트** 그대로 둡니다(프로덕션으로 게시하지 않습니다).


이제 이 두 계정 말고는 **구글 로그인 창 자체를 통과하지 못합니다.**
이름·이메일만 받는 앱이라 구글 심사 대상이 아닙니다.

> 선생님이 한 분 더 늘면 **두 곳**을 함께 고쳐야 합니다 — ① 여기 테스트 사용자 ② 교사 페이지의 허용 계정.
> 한쪽만 넣으면 "허용된 계정이 아닙니다"가 뜹니다.

왼쪽 **클라이언트** → **클라이언트 만들기**

- 이름: `tonggwa2 웹` (아무렇게나)
- **승인된 자바스크립트 원본** → **+ URI 추가** → `https://chwan5256.github.io`
- **승인된 리디렉션 URI 는 비워 둡니다** (페이지를 옮겨 다니는 방식이 아닙니다)

⚠ **가장 많이 틀리는 곳입니다.** 원본에는 **도메인까지만** 넣습니다.

| | |
|---|---|
| 맞는 것 | `https://chwan5256.github.io` |
| 틀린 것 | `https://chwan5256.github.io/tonggwa2/` · `https://chwan5256.github.io/` |

경로나 끝의 `/` 를 붙이면 로그인 단추가 **아예 뜨지 않습니다.**

**만들기** → **클라이언트 ID** (`…apps.googleusercontent.com`) 가 뜹니다. 복사합니다.
**클라이언트 보안 비밀번호(secret)는 쓰지 않습니다.** 어디에도 적지 마세요.

### 3-5. ID 를 두 곳에 넣기

**(가) 웹앱** — `shared/gate.js` 36번째 줄쯤

```js
const CLIENT_ID = '';      // ← 따옴표 사이에 붙여 넣기
```

저장 → GitHub Desktop 에서 커밋·푸시.
⚠ 깃허브 페이지는 바로 바뀌지 않습니다. **1~3분** 기다렸다가 **Ctrl+Shift+R** 로 새로고침해야
새 파일을 읽습니다. F5 만으로는 예전 파일이 그대로 보입니다.

**(나) Apps Script** — 시트 → 확장 프로그램 → Apps Script → `Code.gs` 아래쪽

```js
function 구글로그인_설정() {
  var CLIENT_ID = '';      // ← 같은 값을 넣고
  …
}
```

저장한 뒤 위쪽 함수 칸에서 **구글로그인_설정** 을 고르고 **▶ 실행**.
처음이면 권한 검토 창이 뜹니다 — 계정 선택 → **고급** → **(안전하지 않은 페이지)로 이동** → **허용**.
실행 기록에 `클라이언트 ID 를 저장했습니다: …` 가 나오면 됩니다.

그리고 **§4 의 재배포**(배포 관리 → 편집 → 새 버전)를 반드시 합니다.

### 3-6. 왜 서버까지 확인하나

브라우저가 "나 이 계정이야"라고 말하는 것은 근거가 되지 않습니다 — 개발자 도구로 고칠 수 있습니다.
그래서 구글이 준 **ID 토큰을 Apps Script 로 보내고, 서버가 구글에 직접 물어** 진짜인지 확인한 뒤
허용 계정 목록과 대조합니다(`?mode=gtoken`).
토큰이 **우리 앱을 향해 발급된 것인지**(`aud`)까지 보기 때문에 (나) 단계가 필요합니다.

### 3-7. 안 될 때

| 증상 | 거의 이것입니다 |
|---|---|
| 로그인 단추가 안 뜨고 주소 칸이 나온다 | `gate.js` 가 아직 안 올라갔거나 브라우저가 옛 파일을 봅니다 → 1~3분 뒤 Ctrl+Shift+R |
| 단추 자리가 빈칸으로 남는다 | **승인된 자바스크립트 원본**이 틀렸습니다(경로·끝의 `/`) |
| "액세스 차단됨" | 그 계정이 **테스트 사용자** 목록에 없습니다 |
| "허용된 계정이 아닙니다" | 구글은 통과했는데 **교사 페이지의 허용 계정**에 없습니다 |
| "로그인 정보를 확인하지 못했습니다" | Apps Script 를 재배포하지 않았거나 `구글로그인_설정()` 을 실행하지 않았습니다 |
| "다른 앱에서 발급된 토큰입니다" | (가)와 (나)에 넣은 ID 가 서로 다릅니다 |

### 3-8. 되돌리기

`shared/gate.js` 의 `CLIENT_ID` 를 다시 `''` 로 비우고 푸시하면 예전 방식으로 돌아갑니다.
구글 쪽은 그대로 두어도 아무 일도 일어나지 않습니다. 수업이 막히지 않도록 남겨 둔 길입니다.

## 4. Apps Script 배포

**코드를 고친 뒤에는 반드시 다시 배포해야 반영됩니다.**

1. 구글 시트 → 확장 프로그램 → Apps Script
2. `apps-script/Code.gs` 전체를 붙여 넣고 저장
3. **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**
   - ⚠ **‘새 배포’를 누르면 주소가 바뀝니다.** 반드시 ‘배포 관리 → 편집’입니다.
4. 배포 설정: 실행 계정 = **나**, 액세스 권한 = **링크가 있는 모든 사용자**

교사 화면 맨 위 **구글 연결** 칸이 `연결됨 · ver 6` 으로 나오면 제대로 된 것입니다.
`옛 배포 — 새 버전으로 배포해 주세요` 가 뜨면 3번을 다시 하세요.
**옛 배포 상태에서는 차시 여닫이·오늘 수업·계정 관리·반별 보기가 모두 잠깁니다.**

### 버전을 왜 확인하나
옛 배포는 모르는 요청을 **응답 집계로 흘려보내며 `ok:true`** 를 돌려줍니다.
이것을 걸러내지 않으면 페이지가 그 `ok:true` 를 “계정 맞음 · 비밀번호 맞음”으로 잘못 읽습니다.
그래서 모든 응답에 **어떤 요청에 대한 답인지(`mode`)와 버전(`ver`)** 을 함께 싣고, 그 둘이 맞을 때만 믿습니다.

## 5. 수업 전 확인 (2분)

1. 교사 화면 → **구글 연결**이 `연결됨 · ver 6` 인지
2. **차시 열고 닫기** 칸에서 오늘 할 차시의 **[수업 시작]** 한 번 —
   그 차시를 열고, 오늘 수업으로 정하고, 진행 화면까지 한 번에 갑니다.
3. 미리 준비할 때는 **[오늘 것만 열기]** 로 나머지 차시를 닫아 둡니다.
4. **수업 영상** → 유튜브 주소를 붙여 넣습니다 (진행 화면에서만 재생됩니다)
5. 첫 절에 **접속 QR** 이 크게 나옵니다. 학생은 카메라로 비추면 들어옵니다.

닫아 둔 차시를 ‘오늘 수업’으로 정하면 학생 화면에는 **다른 차시가 올라갑니다.**
교사 화면이 그 어긋남을 계속 경고로 표시하니 함께 열어 주세요.

## 6. 진행 화면 조작

| 키 | 하는 일 |
|---|---|
| `←` `→` | 절 이동 |
| `Space` | 다음 |
| `F` | 전체화면 |
| `R` | 응답판 |
| `Esc` | 나가기 |

왼쪽 위 **[← 자료실]** 로 첫 화면으로 돌아갑니다.
시계는 두 개입니다 — 왼쪽이 이 절의 배정 시간, 오른쪽이 전체. 절 시간의 합은 차시마다 다르며(28~47분),
출석·환기·기기 접속·마무리 시간은 따로 빼 두었습니다.

### 이 화면은 교사만 들어옵니다
진행 화면에는 **학생이 쓴 답안이 그대로** 보이므로, 교사 페이지와 **똑같은 두 단계**
(허용 계정 → 비밀번호)를 거쳐야 열립니다. 주소창에 `?t=1` 을 쳐도 소용없습니다.
한 번 들어오면 이 브라우저에서 **12시간** 기억하고, 위쪽 **[잠그기]** 를 누르면 바로 지워집니다.
공용 컴퓨터에서 수업했다면 나올 때 [잠그기] 를 눌러 주세요.

### [응답 보기] 에서 무엇이 보이나

| 문항 종류 | 보이는 것 |
|---|---|
| 객관식·빈칸·분류·그림 채우기 | **문항 번호 · 절 이름 · 발문**, 그리고 보기별 **막대 + 명수 + 비율**. 정답에 ✓ 표시. 아직 답이 없으면 '아직 응답 없음' |
| 서술형 | 학생이 쓴 **문장 그대로**, 앞에 **반**을 붙여서. 최근 60개까지 |

- 이 페이지에 있는 **모든 문항**이 화면에 그려진 순서대로 나옵니다. 응답이 없어도 빠지지 않습니다.
- 위쪽에서 **반**과 **기간**(전체 / 오늘 / 최근 3시간 / 이번 시간)을 고를 수 있습니다.
  기본은 **전체**입니다 — 지난 시간에 쌓인 답안도 그대로 보입니다.
- 서술형 문장은 **비밀번호로 들어왔을 때만** 보입니다.

## 7. 비밀번호를 바꾼 뒤 꼭 할 일

구글에 닿지 못할 때 쓰는 **예비 경로**는 `teacher.html` 안의 지문(SHA-256)을 봅니다.
비밀번호를 바꾸면 교사 화면이 **새 지문을 화면에 띄워 줍니다.** 그 값을

```js
fallbackPinHash: "…"
```

에 붙여 넣고 커밋·푸시하세요. **이걸 하지 않으면 옛 비밀번호로 계속 들어올 수 있습니다.**
같은 이유로 계정을 더하거나 뺐다면 `fallbackWho` 도 함께 맞춰 주세요.

| 고른 선택지 | 시트 | ○ | ○ (분포만) |
| 맞았는지 틀렸는지 | 학생 기기에만 | × | × |
| 서술형 문장 | 시트 | ○ | ○ (**비밀번호가 있어야** 보입니다) |

학생 이름은 PDF 파일 이름과 학습 기록표에만 쓰입니다. 누가 무엇을 골랐는지는 어디에도 남지 않습니다.
학생이 반을 나중에 바꿔도 **이미 보낸 답은 앞서 고른 반으로 남습니다.**

**반과 이름은 건너뛸 수 없습니다.** 진도를 `반|이름` 으로 갈라 세기 때문입니다.
비워 두면 한 기기를 함께 쓰는 학생들의 진도가 뒤섞입니다.

**진행 화면(#t)은 교사용입니다.** 허용 계정과 비밀번호를 거쳐야 열립니다(§6).

### 시트에 쌓이는 것

| 시트 이름 | 무엇이 | 쓰임 |
|---|---|---|
| `응답` | 모든 응답 한 줄씩 — 시각 · 차시 · 문항 · 선택 · 문장 · 반 | 진행 화면의 분포판이 읽습니다 |
| `서술형 u2-02` 같은 시트 | **서술형만** 차시별로 — 시각 · 반 · 문항 · 답안 | 아카이빙. 반으로 정렬하면 반별 답안 묶음이 됩니다 |

차시별 시트는 **학생이 [다 썼습니다] 를 누른 순간** 자동으로 만들어집니다. 미리 만들어 둘 필요가 없습니다.
`응답` 시트는 빈칸·분류까지 모두 쌓여 금세 수만 줄이 되므로, 답안을 되읽을 때는 차시별 시트를 보세요.
학기말에는 `오래된응답지우기()` 로 `응답` 시트만 정리하면 됩니다 — 차시별 서술형 시트는 남습니다.
