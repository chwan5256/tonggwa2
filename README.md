## 1. 구조

```
읽기 : GitHub Pages (정적 파일)      ← 학생·교사 모두 여기서 화면을 받습니다
쓰기 : Google Apps Script + 시트     ← 설정과 학생 응답은 여기 저장됩니다
```

둘을 물리적으로 나눠 두었습니다. 구글이 막혀도 화면은 뜨고, 파일에 적힌 기본값으로 수업이 이어집니다.

**이것은 잠금이 아니라 허들입니다.** 정적 사이트에는 서버가 없어 완전한 접근 통제를 걸 수 없습니다.
주소를 정확히 아는 사람은 페이지 소스를 볼 수 있습니다.
그래서 **평가 문항·정답·채점기준표는 이 저장소에 두지 않습니다.**

## 2. 교사 화면에 들어가기

두 단계입니다. 둘 다 통과해야 열립니다.

1. **계정 확인** — 허용 목록에 있는 계정인지 봅니다.
2. **비밀번호** — 기본값 `ai2026`. 교사 화면 안에서 바꿀 수 있습니다.

한 번 들어오면 **12시간 동안 그 브라우저에서 기억**합니다. 들어올 때 체크를 풀면 기억하지 않습니다.
위쪽 **[잠그기]** 를 누르면 기억을 지우고 문을 다시 엽니다. **공용 컴퓨터에서는 반드시 잠그고 나오세요.**

기억해 둔 통행증도 새로고침할 때마다 서버에 다시 확인합니다.
다른 기기에서 비밀번호를 바꾸거나 계정을 목록에서 빼면, 이 브라우저도 곧바로 다시 물어봅니다.

### 잠겼을 때
Apps Script 편집기에서 **`설정초기화`** 함수를 실행하세요. 다음 세 경우에 모두 씁니다.

- 비밀번호를 잊었을 때
- 내 계정을 목록에서 실수로 지웠을 때
- 비밀번호를 여러 번 틀려 막혔을 때 (한 시간에 열 번 틀리면 십 분 동안 받지 않습니다)

비밀번호와 계정 목록이 맨 처음 값으로 돌아갑니다.

## 3. 구글 로그인 붙이기 (선택)

붙이지 않아도 씁니다. 지금은 **계정 주소를 직접 입력**하는 방식으로 동작합니다.
구글 로그인을 붙이면 계정을 구글이 확인해 주므로 허들이 한 칸 높아집니다.

1. [Google Cloud Console](https://console.cloud.google.com/) → 프로젝트 만들기
2. **API 및 서비스 → OAuth 동의 화면** → 외부 → 앱 이름·지원 이메일만 채우고 저장
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 자바스크립트 원본**에 `https://chwan5256.github.io` 를 넣습니다
     (리디렉션 URI 는 비워 둡니다)
4. 만들어진 **클라이언트 ID** 를 복사해 `teacher.html` 의

   ```js
   clientId: "",
   ```

   따옴표 안에 붙여 넣고 커밋·푸시합니다.

원본 주소가 정확히 맞아야 합니다. 틀리면 로그인 창이 뜨지 않고, 그때는 자동으로 직접 입력 방식으로 돌아갑니다.

## 4. Apps Script 배포

**코드를 고친 뒤에는 반드시 다시 배포해야 반영됩니다.**

1. 구글 시트 → 확장 프로그램 → Apps Script
2. `apps-script/Code.gs` 전체를 붙여 넣고 저장
3. **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**
   - ⚠ **‘새 배포’를 누르면 주소가 바뀝니다.** 반드시 ‘배포 관리 → 편집’입니다.
4. 배포 설정: 실행 계정 = **나**, 액세스 권한 = **링크가 있는 모든 사용자**

교사 화면 맨 위 **구글 연결** 칸이 `연결됨 · ver 5` 으로 나오면 제대로 된 것입니다.
`옛 배포 — 새 버전으로 배포해 주세요` 가 뜨면 3번을 다시 하세요.
**옛 배포 상태에서는 차시 여닫이·오늘 수업·계정 관리·반별 보기가 모두 잠깁니다.**

### 버전을 왜 확인하나
옛 배포는 모르는 요청을 **응답 집계로 흘려보내며 `ok:true`** 를 돌려줍니다.
이것을 걸러내지 않으면 페이지가 그 `ok:true` 를 “계정 맞음 · 비밀번호 맞음”으로 잘못 읽습니다.
그래서 모든 응답에 **어떤 요청에 대한 답인지(`mode`)와 버전(`ver`)** 을 함께 싣고, 그 둘이 맞을 때만 믿습니다.

## 5. 수업 전 확인 (2분)

1. 교사 화면 → **구글 연결**이 `연결됨 · ver 5` 인지
2. **차시 열고 닫기** 칸에서 오늘 할 차시의 **[수업 시작]** 한 번 —
   그 차시를 열고, 오늘 수업으로 정하고, 진행 화면까지 한 번에 갑니다.
3. 미리 준비할 때는 **[오늘 것만 열기]** 로 나머지 차시를 닫아 둡니다.
4. **수업 영상** → 유튜브 주소를 붙여 넣습니다 (진행 화면에서만 재생됩니다)
5. 첫 절에 **접속 QR** 이 크게 나옵니다. 학생은 카메라로 비추면 들어옵니다.

닫아 둔 차시를 ‘오늘 수업’으로 정하면 학생 화면에는 **다른 차시가 올라갑니다.**
교사 화면이 그 어긋남을 계속 경고로 표시하니 함께 열어 주세요.

## 6. 진행 화면 조작

| 키 | 하는 일 |
|---|---|
| `←` `→` | 절 이동 |
| `Space` | 다음 |
| `F` | 전체화면 |
| `R` | 응답판 |
| `Esc` | 나가기 |

왼쪽 위 **[← 자료실]** 로 첫 화면으로 돌아갑니다.
시계는 두 개입니다 — 왼쪽이 이 절의 배정 시간, 오른쪽이 전체. 절 시간의 합은 **40분**이고,
출석·환기·기기 접속·마무리 10분은 따로 빼 두었습니다.

## 7. 비밀번호를 바꾼 뒤 꼭 할 일

구글에 닿지 못할 때 쓰는 **예비 경로**는 `teacher.html` 안의 지문(SHA-256)을 봅니다.
비밀번호를 바꾸면 교사 화면이 **새 지문을 화면에 띄워 줍니다.** 그 값을

```js
fallbackPinHash: "…"
```

에 붙여 넣고 커밋·푸시하세요. **이걸 하지 않으면 옛 비밀번호로 계속 들어올 수 있습니다.**
같은 이유로 계정을 더하거나 뺐다면 `fallbackWho` 도 함께 맞춰 주세요.

## 7-1. 반과 이름 — 무엇이 어디까지 가는가

| | 어디에 저장 | 구글로 전송 | 선생님이 볼 수 있나 |
|---|---|---|---|
| **반** | 학생 기기 + 시트 | ○ | ○ (반별 응답 수) |
| **이름** | **학생 기기에만** | **×** | **×** |
| 고른 선택지 | 시트 | ○ | ○ (분포만) |
| 맞았는지 틀렸는지 | 학생 기기에만 | × | × |
| 서술형 문장 | 시트 | ○ | ○ (**비밀번호가 있어야** 보입니다) |

학생 이름은 PDF 파일 이름과 학습 기록표에만 쓰입니다. 누가 무엇을 골랐는지는 어디에도 남지 않습니다.
학생이 반을 나중에 바꿔도 **이미 보낸 답은 앞서 고른 반으로 남습니다.**

**진행 화면(#t)은 교사용입니다.** 교사 화면에서 한 번 들어온 기기이거나 교사 화면의 링크로 열었을 때만 열립니다.
학생 기기에서 `T` 키를 눌러도 열리지 않습니다.

## 8. 학생 개인정보

- 학생 응답은 **차시 코드·문항 코드·선택지·짧은 문장**만 저장합니다.
- 이름·학번·이메일은 **받지 않습니다.**
- 이름이 필요한 과제는 이 경로를 쓰지 않고 **구글 폼·클래스룸**으로 보냅니다. 그 경계선이 이 설계의 안전장치입니다.
- 학기말에 `오래된응답지우기` 함수로 한 달 넘은 응답을 지웁니다.
- **비밀번호는 주소에 실려 나갑니다.** JSONP 구조상 그렇습니다(Apps Script 실행 기록·브라우저 방문 기록에 남습니다).
  그래서 이 비밀번호는 '수업 운영 설정을 지키는 빗장'이지 계정 암호가 아닙니다. 다른 곳에 쓰는 암호를 넣지 마세요.
