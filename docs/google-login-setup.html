구글 로그인 붙이기

지금은 계정 주소를 치기만 하면 비밀번호 칸이 열립니다. 주소는 누구나 칠 수 있습니다. 구글 로그인을 붙이면 그 계정으로 실제 로그인한 사람만 다음 칸으로 갑니다. 한 번만 하면 되고, 넉넉히 잡아 15분입니다.

무엇이 달라지는가

지금 — 허들

1단계에서 주소를 칩니다. chwan5256@namkang.sen.hs.kr 을 아는 학생이라면 여기까지 옵니다. 막는 것은 사실상 비밀번호 하나입니다.

붙인 뒤 — 잠금

1단계에 구글 로그인 단추만 있습니다. 그 계정의 비밀번호로 실제 로그인해야 비밀번호 칸이 열립니다. 주소를 아는 것은 아무 소용이 없습니다.

더 중요한 것은 확인하는 자리입니다. 브라우저가 “나 이 계정이야”라고 말하는 것은 개발자 도구로 고칠 수 있습니다. 그래서 구글이 준 증표를 Apps Script 로 보내고, 서버가 구글에 직접 물어 확인합니다. 이 확인은 학생 기기에서 손댈 수 없습니다.

미리 알아 둘 것

  • 돈이 들지 않습니다. 구글 클라우드 계정을 만들지만 결제 정보는 넣지 않습니다.
  • 어느 계정으로 해도 됩니다. cadrical@gmail.com 으로 만들어도 학교 계정으로 로그인하는 데 지장이 없습니다.
  • 중간에 멈춰도 됩니다. 아래 각 단계의 [했습니다] 를 누르면 이 브라우저가 기억합니다.
  • 구글 화면은 종종 바뀝니다. 메뉴 이름이 조금 달라도 하는 일은 같으니 비슷한 이름을 찾으세요.

  7. Apps Script 에도 같은 ID 를 넣고 한 번 실행합니다

    구글 시트 → 확장 프로그램 → Apps Script

    학생 응답이 쌓이는 구글 시트를 열고 확장 프로그램 → Apps Script 로 들어갑니다.

    Code.gs 아래쪽에 구글로그인_설정 이라는 함수가 있습니다. 찾기 어려우면 Ctrl+F 로 구글로그인_설정 을 찾으세요.

    function 구글로그인_설정() {
  var CLIENT_ID = '여기에_클라이언트_ID';
  PropertiesService.getScriptProperties().setProperty('clientid', CLIENT_ID);
  Logger.log('클라이언트 ID 를 저장했습니다: ' + (CLIENT_ID || '(비움)'));
}

    ID 를 넣고 저장(💾)한 다음, 화면 위쪽 함수 고르는 칸에서 구글로그인_설정 을 고르고 ▶ 실행 을 누릅니다. 처음 실행하면 권한 검토 창이 뜹니다 — 본인 계정을 고르고 고급 → (안전하지 않은 페이지)로 이동 → 허용.

    아래 실행 기록에 클라이언트 ID 를 저장했습니다: … 가 나오면 된 것입니다.

    왜 서버에도 넣나요? 서버가 “이 증표가 우리 앱을 향해 발급된 것인가”까지 확인하기 위해서입니다. 이걸 넣지 않으면 다른 사이트에서 받은 증표도 통과할 수 있습니다.

    실행 기록에 저장했다는 줄이 보입니다.

  8. Apps Script 를 다시 배포합니다

    Apps Script → 배포 → 배포 관리

    코드를 고쳤으니 다시 배포해야 반영됩니다. ‘새 배포’가 아니라 ‘배포 관리’ 입니다.

    • 오른쪽 위 배포 → 배포 관리
    • 목록에 있는 배포의 ✏️ 연필 을 누릅니다
    • 버전 을 새 버전 으로 바꾸고 배포
    ‘새 배포’를 누르면 주소가 바뀝니다. 주소가 바뀌면 모든 차시 파일의 LESSON.api 를 다 고쳐야 합니다. 반드시 배포 관리 → 편집(연필) 로 하세요.

    교사 페이지 맨 위 구글 연결 칸이 연결됨 · ver 6 으로 나옵니다.

  9. 확인합니다

    교사 페이지 · 수업 진행 화면

    세 가지를 봅니다.

    • 교사 페이지(teacher.html)를 열면 1단계에 구글 로그인 단추가 뜬다
    • 로그인하면 “허용된 계정입니다 — 내 주소” 가 뜨고 비밀번호 칸이 열린다
    • 차시 페이지에서 T 를 눌러도 같은 문이 뜨고, 거기에도 구글 단추가 있다

    학생 기기에서 확인하고 싶으면, 다른 브라우저의 시크릿 창으로 차시 주소 뒤에 #t 를 붙여 열어 보세요. 문이 뜨고 통과하지 못하면 제대로 된 것입니다.

    세 가지가 모두 그렇게 됩니다.

안 될 때

이런 증상거의 이것입니다
로그인 단추가 안 뜨고 예전처럼 주소 칸이 나온다 gate.js 가 아직 안 올라갔거나 브라우저가 옛 파일을 보고 있습니다. 푸시하고 1~3분 뒤 Ctrl+Shift+R.
단추 자리가 빈칸으로 남는다 승인된 자바스크립트 원본이 틀렸습니다. https://chwan5256.github.io 하나만, 뒤에 / 나 경로 없이. 고친 뒤 몇 분 걸릴 수 있습니다.
로그인하니 “액세스 차단됨” 이 뜬다 그 계정이 테스트 사용자 목록에 없습니다. 3단계로 돌아가 추가하세요.
“허용된 계정이 아닙니다” 가 뜬다 구글은 통과했는데 교사 페이지의 허용 계정 목록에 없습니다. 두 목록은 별개입니다.
“로그인 정보를 확인하지 못했습니다” Apps Script 를 다시 배포하지 않았습니다(8단계). 또는 7단계의 함수를 실행하지 않았습니다.
“다른 앱에서 발급된 토큰입니다” 7단계에 넣은 ID 와 6단계에 넣은 ID 가 서로 다릅니다. 같은 값이어야 합니다.
연결 칸이 옛 배포 라고 나온다 8단계를 다시 하세요. ‘새 배포’ 말고 배포 관리 → 편집 → 새 버전.

되돌리려면

shared/gate.js 의 CLIENT_ID 를 다시 '' 로 비우고 푸시하면 예전처럼 계정 주소를 치는 방식으로 돌아갑니다. 구글 쪽은 그대로 두어도 아무 일도 일어나지 않습니다. 급할 때 수업이 막히지 않도록 남겨 둔 길입니다.
