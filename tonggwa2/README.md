# 통합과학2 수업 자료실

2022 개정 교육과정 통합과학2 지구과학 파트의 차시별 수업 웹 자료입니다.
학생은 링크만 누르면 되고, 로그인도 설치도 필요하지 않습니다.

---

## 1. 처음 한 번만 하는 일 — 설치와 배포

명령어는 쓰지 않습니다. 전부 화면에서 클릭합니다. 처음 한 번만 20분쯤 걸립니다.

### 1-1. 계정과 프로그램

1. **github.com** 에서 계정을 만듭니다 (무료).
2. **GitHub Desktop** 을 내려받아 설치하고, 만든 계정으로 로그인합니다.
   <https://desktop.github.com>

### 1-2. 저장소 만들기

3. GitHub Desktop 왼쪽 위 **File → New repository**
4. 이렇게 채웁니다.

   | 칸 | 값 |
   |---|---|
   | Name | `tonggwa2` |
   | Local path | `C:\repos` — 아래 주의사항을 꼭 보세요 |
   | Initialize this repository with a README | **체크 해제** (이미 README가 있습니다) |
   | Git ignore / License | 그대로 둡니다 |

   > ⚠️ **저장 위치 주의.** 기본값이 `문서\GitHub`인데, 문서 폴더가 OneDrive와 동기화 중이면 저장소가 깨질 수 있습니다.
   > **구글 드라이브(I:) 안에도 절대 두지 마세요.** 동기화 프로그램이 `.git` 폴더와 충돌합니다.
   > `C:\repos` 처럼 아무것도 동기화하지 않는 평범한 로컬 폴더가 안전합니다. 폴더가 없으면 새로 만들면 됩니다.

5. **Create repository** 를 누르면 `C:\repos\tonggwa2` 폴더가 생깁니다.

### 1-3. 파일 넣고 올리기

6. 탐색기에서 이 `tonggwa2` 폴더를 열고, 안에 있는 것을 **전부 선택**(Ctrl+A)해 `C:\repos\tonggwa2\` 안으로 복사합니다.
7. GitHub Desktop으로 돌아오면 바뀐 파일 목록이 보입니다. 왼쪽 아래 Summary 칸에 `첫 커밋` 이라고 쓰고 **Commit to main**.
8. **Publish repository** 를 누릅니다.
   - **"Keep this code private" 체크를 반드시 해제하세요.** 무료 계정은 공개 저장소에서만 다음 단계의 Pages를 쓸 수 있습니다.

### 1-4. 사이트 켜기

9. github.com에서 방금 만든 `tonggwa2` 저장소로 갑니다.
10. 위쪽 **Settings** → 왼쪽 **Pages** → Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 두고 **Save**.
11. 1~2분 뒤 같은 화면에 주소가 나타납니다.

```
https://{내아이디}.github.io/tonggwa2/
```

이 주소가 **자료실 주소**입니다. 학기 초에 클래스룸 '자료'로 한 번 올려 상단에 고정하세요.
각 차시 주소는 그 아래에 붙습니다 — `https://{내아이디}.github.io/tonggwa2/u2/01-energy-budget/`

### 1-5. Cowork에 폴더 연결

12. Claude 데스크톱 앱에서 **폴더 추가**로 `C:\repos\tonggwa2` 를 연결합니다.

이제 수정 요청을 하면 제가 이 폴더에 직접 씁니다.

> **정본은 이제 `C:\repos\tonggwa2` 한 곳입니다.**
> 구글 드라이브의 `[웹앱]\tonggwa2\` 사본은 참고용으로만 남기고, 앞으로 고치지 않습니다.
> 두 곳을 같이 고치기 시작하면 어느 쪽이 최신인지 알 수 없게 됩니다.

## 2. 수정한 것을 사이트에 반영하기

설정이 끝난 뒤부터는 이것만 반복합니다.

1. 대화창에서 고쳐 달라고 말합니다 → 제가 `C:\repos\tonggwa2` 에 씁니다
2. **GitHub Desktop을 엽니다.** 바뀐 파일과 **바뀐 줄이 그대로 보입니다.**
3. 내용을 확인합니다. 마음에 안 드는 파일은 왼쪽 체크를 풀면 이번에 올라가지 않습니다.
4. Summary에 무엇을 바꿨는지 한 줄 (`시뮬레이터 눈금 수정`) → **Commit to main**
5. 오른쪽 위 **Push origin**
6. 1~2분 뒤 사이트에 반영됩니다

**되돌리기.** GitHub Desktop 위쪽 **History** 탭에 지금까지의 모든 변경이 쌓입니다.
잘못된 커밋을 오른쪽 클릭 → **Revert changes in commit** 하면 그 변경만 취소됩니다.
여러 번 고쳐도 언제든 이전 상태로 돌아갈 수 있으니, 과감하게 고치셔도 됩니다.

> 한 번에 여러 곳을 고칠 때는 제가 다 고친 뒤에 한 번만 커밋하시면 됩니다. 파일마다 커밋할 필요가 없습니다.

## 3. 차시를 하나 추가할 때

1. `u2/` 또는 `u3/` 아래에 폴더를 하나 만들고 그 안에 `index.html`을 넣습니다.
   폴더 이름은 **영문·숫자·붙임표만** 씁니다 (예: `02-el-nino`). 한글 폴더명은 주소가 깨질 수 있습니다.
2. `manifest.json`의 `lessons` 배열에 **한 줄 추가**합니다.

```json
{
  "unit": "u2",
  "no": "02",
  "title": "엘니뇨는 왜 반대편에 홍수를 일으키나",
  "std": "[10통과2-02-03]",
  "path": "u2/02-el-nino/",
  "used": null,
  "form": ""
}
```

3. GitHub Desktop에서 **Commit → Push**. (2장과 같습니다)

**자료실 첫 화면(`index.html`)은 손대지 않습니다.** `manifest.json`을 읽어 카드를 자동으로 만듭니다.

| 항목 | 뜻 |
|---|---|
| `unit` | `u2`(환경과 에너지) 또는 `u3`(과학과 미래 사회) |
| `no` | 그 단원 안에서의 차시 번호 |
| `std` | 성취기준 코드 |
| `path` | 폴더 경로. **끝에 `/`를 꼭 붙입니다** |
| `used` | **실제로 수업에 쓴 날**. `"2026-09-12"` 형식. 안 썼으면 `null` |
| `form` | 그 차시 구글 폼 주소 (선택) |

## 4. 구글 폼 연결

각 차시 `index.html` 맨 아래에 이 부분이 있습니다.

```js
const LESSON = {
  form: ""   // ← 여기에 구글 폼 주소를 붙여 넣으세요
};
```

따옴표 안에 폼 주소를 넣으면 '제출 양식 열기' 버튼이 살아납니다. 비워 두면 버튼이 흐려지고 안내 문구가 뜹니다.

**클래스룸 운영 순서**

1. 그 차시 구글 폼을 만듭니다
2. 폼 주소를 위 `form:`에 넣고 GitHub Desktop에서 Commit → Push 합니다
3. 클래스룸에 **과제**를 만들어 ① 차시 페이지 링크와 ② 같은 폼을 함께 첨부합니다

> 폼을 페이지 안에 창으로 끼워 넣는 방식(iframe)은 권하지 않습니다.
> 학교 계정 로그인이 필요한 폼은 끼워 넣은 창 안에서 로그인 화면이 막히는 경우가 있습니다.
> 새 탭으로 여는 지금 방식이 어떤 기기에서도 안정적입니다.

## 5. 폴더 구조

```
tonggwa2/
├── index.html          자료실 첫 화면 — 손대지 않습니다
├── manifest.json       차시 목록 — 여기만 고칩니다
├── README.md           이 안내문
├── shared/
│   ├── base.css        공통 디자인 — 한 번 정하고 고정합니다
│   └── lib.js          공통 기능 (테마·퀴즈·그래프)
├── u2/                 Ⅱ. 환경과 에너지
│   └── 01-energy-budget/index.html
└── u3/                 Ⅲ. 과학과 미래 사회
```

## 6. 오래 쓰기 위한 규칙 셋

1. **템플릿은 한 번만 만듭니다.** 차시마다 새 디자인을 하지 않습니다. `shared/base.css`와 기존 레이아웃을 그대로 씁니다. 그래야 만드는 쪽도 쓰는 쪽도 매번 새로 익히지 않습니다.
2. **수업에 한 번 써 본 것만 남깁니다.** `used` 날짜가 비어 있는 자료가 쌓이기 시작하면 자료실이 아니라 창고가 됩니다. 학기말에 `used`가 `null`인 항목은 지우거나 다음 학기로 넘깁니다.
3. **한 차시는 한 파일입니다.** 파일을 쪼개지 않습니다. 1년 뒤에 열어서 고칠 수 있어야 합니다.

## 7. 자주 겪는 문제

| 증상 | 원인과 해결 |
|---|---|
| 자료실 화면에 "목록을 불러오지 못했습니다" | 파일을 컴퓨터에서 직접 열었을 때 나옵니다(`file://`). GitHub Pages 주소로 여세요. |
| 차시 카드를 눌렀는데 404 | `manifest.json`의 `path` 끝에 `/`가 빠졌거나 폴더 이름이 다릅니다. 대소문자도 구분합니다. |
| 글꼴이 다르게 보임 | 학교망에서 구글 폰트가 차단된 경우입니다. 기본 글꼴로 표시되며 내용에는 문제가 없습니다. |
| 그래프가 안 보임 | `shared/lib.js`가 함께 올라갔는지 확인하세요. |
| 바꿨는데 그대로임 | GitHub Desktop에서 **Push origin** 을 눌렀는지 먼저 확인하세요. 커밋만 하고 푸시를 안 하면 사이트는 그대로입니다. 푸시했다면 1~2분 뒤 `Ctrl+Shift+R`로 새로 고칩니다. |
| GitHub Desktop에 아무 변경도 안 보임 | 파일을 `C:\repos\tonggwa2` 가 아니라 구글 드라이브 쪽 사본에 저장했을 수 있습니다. Cowork에 연결한 폴더가 맞는지 확인하세요. |
