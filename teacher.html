교사 전용

수업 운영 화면

오늘 수업을 정하고, 차시를 열고 닫고, 진행 화면으로 바로 들어갑니다. 이 주소는 학생 화면 어디에도 연결해 두지 않았습니다.

구글 연결

설정과 학생 응답이 구글에 저장됩니다. 연결이 끊기면 파일에 적힌 기본값(manifest.json)이 그대로 쓰이므로 수업은 멈추지 않습니다.

확인하는 중…
연결되지 않았습니다. 아래를 순서대로 확인해 주세요.
  1. Apps Script 편집기에서 Code.gs 전체를 최신 코드로 교체했는지
  2. 저장한 뒤 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포를 눌렀는지
    ‘새 배포’를 누르면 주소가 바뀝니다. 반드시 ‘배포 관리 → 편집’입니다.
  3. 배포 설정이 실행 계정 = 나, 액세스 권한 = 링크가 있는 모든 사용자인지
  4. 맨 처음 배포할 때 뜨는 권한 승인을 끝까지 눌렀는지

오늘 수업

학생 자료실 맨 위 ‘오늘 수업’ 카드에 어떤 차시를 띄울지 선생님이 직접 정합니다. 고른 뒤 [저장]을 눌러야 학생 화면에 반영됩니다. 저장 전에는 아무것도 바뀌지 않습니다.

차시 열고 닫기

닫아 둔 차시는 학생 목록에서 사라지고, 주소를 직접 입력해도 안내문만 나옵니다. 바꾸면 곧바로 반영됩니다. 들어올 때 비밀번호를 이미 확인했으므로 여기서 다시 넣지 않아도 됩니다.

알아 두실 것. 이것은 잠금이 아니라 허들입니다. 주소를 정확히 아는 사람은 페이지 소스로 내용을 볼 수 있습니다. 미리보기를 막는 용도로만 쓰세요.

들어올 수 있는 계정

이 목록에 있는 계정만 위 입장 문을 통과합니다. 주소를 고치거나, 줄을 지우거나, 새로 더한 뒤 저장을 누르세요. 계정은 최소 한 개가 남아 있어야 합니다.

비밀번호 바꾸기

예비 비밀번호도 함께 바꿔 주세요. 구글에 닿지 못할 때 쓰는 예비 경로는 teacher.html 안의 지문을 봅니다. 이 값을 바꾸지 않으면 옛 비밀번호로 계속 들어올 수 있습니다.
  1. teacher.html 의 fallbackPinHash 를 아래 값으로 바꿉니다
  2. 저장하고 GitHub Desktop 에서 커밋·푸시합니다

잠겼을 때. 비밀번호를 잊었거나, 내 계정을 실수로 지웠거나, 여러 번 틀려 막혔을 때는 Apps Script 편집기에서 설정초기화 함수를 실행하세요. 맨 처음 비밀번호와 계정 목록으로 돌아갑니다.

반 목록

학생이 처음 들어올 때 고르는 반입니다. 여기서 정한 반으로 응답이 나뉘어 쌓이고, 진행 화면에서 반별로 골라 볼 수 있습니다. 학생 이름은 저장되지 않습니다.

학생 접속 QR

칠판에 띄우면 학생이 주소를 받아 적지 않고 카메라로 바로 들어옵니다. 진행 화면 첫 절에도 같은 그림이 자동으로 나옵니다.

학생 자료실 주소

구글 클래스룸에는 이 주소만 올리세요. 교사 화면 주소는 어디에도 걸려 있지 않습니다.

수업 영상

유튜브 주소를 그대로 붙여 넣으면 됩니다. 어떤 형태든(watch·youtu.be·shorts) 알아서 영상 번호만 뽑아 저장합니다. 저장한 영상은 진행 화면(#t)에서만 재생되고 학생 화면에는 나타나지 않습니다.

다음에 또 하실 때. 이 페이지에 들어와 주소만 바꿔 붙이면 끝입니다. 코드를 고치거나 다시 배포할 필요가 없습니다. 비우고 저장하면 그 자리는 다시 ‘영상 없음’으로 돌아갑니다.
