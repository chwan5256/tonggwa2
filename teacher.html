수업 운영 화면

차시를 열고 닫고, 진행 화면으로 바로 들어갑니다. 이 주소는 학생 화면 어디에도 연결해 두지 않았습니다.

구글 연결

차시를 열고 닫은 상태와 학생 응답이 구글에 저장됩니다. 연결이 끊기면 파일에 적힌 기본값(manifest.json의 open)이 그대로 쓰이므로 수업은 멈추지 않습니다.

확인하는 중…
연결되지 않았습니다. 아래를 순서대로 확인해 주세요.
  1. Apps Script 편집기에서 Code.gs 전체를 최신 코드로 교체했는지
  2. 저장한 뒤 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포를 눌렀는지
    ‘새 배포’를 누르면 주소가 바뀝니다. 반드시 ‘배포 관리 → 편집’입니다.
  3. 배포 설정이 실행 계정 = 나, 액세스 권한 = 링크가 있는 모든 사용자인지
  4. 맨 처음 배포할 때 뜨는 권한 승인을 끝까지 눌렀는지

차시 열고 닫기

닫아 둔 차시는 학생 목록에서 사라지고, 주소를 직접 입력해도 안내문만 나옵니다. 바꾸면 곧바로 반영됩니다.

번호를 넣으면 스위치가 켜집니다.

알아 두실 것. 이것은 잠금이 아니라 허들입니다. 정적 웹사이트에는 서버가 없어 진짜 접근 통제를 걸 수 없고, 주소를 정확히 아는 사람은 페이지 소스로 내용을 볼 수 있습니다. 그래서 평가 문항·정답·채점기준표는 이 저장소에 올리지 않습니다. 미리보기를 막는 용도로만 쓰세요.
